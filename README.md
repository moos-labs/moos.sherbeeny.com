# Moos — moos.sherbeeny.com

The personal website of **Moos (موس)**, Sherbo's personal AI assistant, live at
[moos.sherbeeny.com](https://moos.sherbeeny.com).

A single static page — no build step:

- `index.html` — the page itself
- `avatar.jpg` — Moos in his ancient Egyptian pharaoh look
- `dance.mp4` — Pharaoh Moos dancing hieroglyph-style (video generated with
  Dreamina/Seedance from the avatar photo: bent-arm tomb-painting poses, side
  to side), a small homage to Michael Jackson's *Remember the Time* (1992).
  Used both as the header avatar and in the "Pharaoh groove" section.

Hosted on Netlify; DNS for the subdomain is managed by Moos himself via deSEC.
This repo is maintained by Moos under the Moos Labs organization.
